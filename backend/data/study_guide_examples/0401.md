# 0401 고성능 딥러닝 학습지

## 학습 목표

- CNN이 이미지에서 지역 패턴을 학습하는 방식을 설명한다.
- Conv / Pool / FC 파이프라인을 설계·계산할 수 있다.

## 핵심 개념

- **Convolution**: 공유 가중치 필터로 translation equivariance.
- **Padding / Stride**: 출력 크기·수용 영역(receptive field) 조절.
- **Pooling**: 공간 해상도 축소, 위치 변화에 강건.
- **Receptive field**: 깊어질수록 더 넓은 영역을 본다.
- **전이학습**: ImageNet pretrained backbone + fine-tune.

## 수식·정의

- Conv 출력 크기: $O = \lfloor (I - K + 2P) / S \rfloor + 1$
- 파라미터 수: $K^2 \cdot C_{in} \cdot C_{out}$ (+ bias)

## 직관

- 초기 층은 edge·texture, 깊은 층은 part·object에 가깝은 feature를 학습하는 경향이 있다.

## 예제

1. $224\times224$ 입력, $7\times7$ conv stride 2 padding 3 의 출력 spatial size는?
2. FC layer가 많을수록 파라미터·과적합에 어떤 영향?

## 체크리스트

- [ ] conv layer 출력 크기 공식을 쓸 수 있다
- [ ] pooling의 목적을 두 가지 이상 말할 수 있다
- [ ] transfer learning 절차를 순서대로 설명할 수 있다

# 0304 고성능 딥러닝 학습지

## 학습 목표

- 단층·다층 신경망의 순전파 과정을 설명할 수 있다.
- 역전파가 gradient를 계산하는 원리를 말로 풀 수 있다.
- 활성화 함수와 손실 함수의 역할을 구분한다.

## 핵심 개념

- **퍼셉트론**: 가중합 + 활성화로 이진 분류; XOR는 단층으로 불가.
- **MLP**: 은닉층을 통해 비선형 결정 경계 학습.
- **역전파**: 체인룰로 $\partial L / \partial w$ 를 효율적으로 계산.
- **활성화 함수**: ReLU, sigmoid, tanh — 비선형성·기울기 소실 trade-off.
- **손실 함수**: MSE(회귀), Cross-Entropy(분류).

## 수식·정의

- 순전파: $z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$, $a^{(l)} = \sigma(z^{(l)})$
- 경사 하강: $w \leftarrow w - \eta \frac{\partial L}{\partial w}$
- Cross-Entropy (이진): $L = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$

## 직관

- 역전파는 “출력 오차가 각 가중치에 얼마나 기여했는지”를 거꾸로 전달하는 과정이다.
- ReLU는 양수 구간에서 기울기가 1이라 vanishing gradient를 완화한다.

## 예제

1. 2→4→1 MLP에서 은닉층 유닛 수를 늘리면 표현력과 과적합 위험이 어떻게 변하는가?
2. sigmoid vs ReLU를 은닉층에 쓸 때 학습 속도 차이를 설명하라.

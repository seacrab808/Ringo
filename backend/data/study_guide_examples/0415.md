# 0415 고성능 딥러닝 학습지

## 학습 목표

- Attention이 “어디를 볼지”를 학습한다는 점을 설명한다.
- Transformer encoder block 구조를 그릴 수 있다.

## 핵심 개념

- **Attention score**: Query·Key 유사도 → Value 가중합.
- **Scaled Dot-Product**: $\text{softmax}(QK^T/\sqrt{d_k})V$
- **Multi-Head**: 여러 subspace에서 parallel attention.
- **Positional Encoding**: 순서 정보를 embedding에 주입 (sinusoidal 또는 learned).
- **Encoder-Decoder**: 기계번역 등 seq2seq; decoder는 masked self-attn + cross-attn.

## 수식·정의

- $\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
- FFN block: 두 linear + ReLU/GELU, residual + layer norm

## 직관

- Self-attention은 모든 토큰 쌍의 관계를 한 번에 보므로 장거리 의존성에 강하다 (복잡도 $O(n^2)$).

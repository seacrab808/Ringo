# 0408 고성능 딥러닝 학습지

## 학습 목표

- 시퀀스 데이터에 RNN 계열을 적용하는 이유를 설명한다.
- LSTM/GRU가 long-term dependency를 돕는 메커니즘을 이해한다.

## 핵심 개념

- **RNN**: 동일 가중치를 시간에 공유; hidden state $h_t$ 가 memory.
- **BPTT**: 시간 축으로 펼친 graph에 역전파; truncated BPTT로 비용 절감.
- **Vanishing gradient**: 긴 시퀀스에서 먼 과거 기여 소실.
- **LSTM**: cell state + gate(input, forget, output) 로 gradient highway.
- **GRU**: LSTM 단순화; update·reset gate.

## 수식·정의

- $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b)$
- LSTM forget gate: $f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$

## 직관

- LSTM의 cell state는 “기차선로”처럼 정보가 멀리 전달될 통로를 열어 준다.

# 0318 고성능 딥러닝 학습지

## 학습 목표

- 다양한 최적화 알고리즘의 차이를 설명한다.
- 과적합을 막는 정규화 기법을 상황에 맞게 고른다.

## 핵심 개념

- **SGD / Mini-batch**: 노이즈 있는 gradient로 빠른 수렴.
- **Momentum / Adam**: 과거 gradient 정보로 진동·plateau 완화.
- **Weight Decay (L2)**: 가중치 크기 페널티 → 단순한 모델 유도.
- **Dropout**: 학습 시 뉴런 무작위 off → 앙상블 효과.
- **Batch Normalization**: 층 입력 분포 안정화 → 학습 가속.

## 수식·정의

- SGD: $\theta_{t+1} = \theta_t - \eta g_t$
- Adam: 1차·2차 모멘트 $m_t, v_t$ 로 adaptive step
- L2 정규: $L' = L + \frac{\lambda}{2}\|\theta\|^2$

## 직관

- BN은 “각 층이 항상 비슷한 스케일의 입력을 받는다”고 가정해 learning rate 튜닝을 쉽게 한다.
- Dropout은 co-adaptation을 줄여 일반화에 도움을 준다.

## 예제

1. batch size를 키우면 gradient noise와 메모리·수렴에 어떤 영향이 있는가?
2. train loss ↓ / val loss ↑ 패턴이 보이면 어떤 정규화를 먼저 시도할 것인가?

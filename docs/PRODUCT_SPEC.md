# Ringo 제품 스펙 (확정)

> 사용자 확인 반영 · 2026-05-27

## MVP (S — 반드시 먼저)

1. **채팅 자연어 등록** → Task + (해당 시) 타임블록
2. **모트모트형 Task + 타임테이블** (한 화면, 색 연동)
3. **자료 요약 자동화** — 원본 보관 + 글 요약 + 요약 PDF (Task 하위 페이지)

이후: 습관 트래커, 반복/휴강, GCal 동기화, AI 리포트·알림.

---

## 하루 화면 (모트모트)

- 날짜를 바꾸면 **같은 레이아웃**, 해당일 Task·블록·일기만 교체
- **좌 TASK**: 상세(제목·메모·카테고리·마감 등), 드래그 정렬
- **우 TIMETABLE**: 요약 라벨 + **Task와 동일 highlight 색**
- **하단**: 하루 **일기 1편** 고정 (반려견 케어 노트 없음)
- 시간축: **06:00 ~ 익일 05:00** (24칸, 모트모트)

### Task 정렬

1. `is_time_fixed` → `start` 시각 오름차순
2. 시간 없음 → `created_order` (등록 순)
3. 마감만 있는 일정(`deadline`, 시간 없음) → 시간 없는 구역, 마감일 표시

### 시간 블록

- 종료 미언급 → **기본 1시간** (`DEFAULT_DURATION_MINUTES = 60`)
- 채팅으로 나중에 “2시로 옮겨줘” → `is_time_fixed` + 블록 생성 (E)

## 일정 유형 (A, B)

| 유형 | 예시 | 필드 |
|------|------|------|
| **시각 고정** | 금요일 14시 딥러닝 | `start`, `end`(자동 +1h) |
| **마감** | 이번주 금요일까지 보고서 | `deadline`, `is_time_fixed=false` |
| **미정** | “이거 해야 함” | 정렬만 하단 |

둘 다 동시 가능 (예: 마감 금요일 + 수요일 2시 작업 블록).

---

## 반복 · 휴강 (F, G)

- 타임테이블: **매주 반복 블록** (개강~종강)
- Task 리스트: **과목/역할 이름** 한 줄 (예: `소프트웨어공학 수업`, `SW창업 조교`)
- **그날만 휴강(취소)** — 보강 기능 없음 (나중에 자연어로 별도 추가)

---

## 카테고리 (H)

- 사용자 **무제한 생성** (외주, 회의, 개인일정, …)
- 각 카테고리: `name`, `color` (hex) — Task 하이라이트 = 타임블록 배경
- 파서 기본 제안: class, ta, research, health, personal, other + **자유 문자열 slug**

---

## Task 하위 페이지 · 자료 (I, J)

노션형 1 Task = 1 페이지:

| 탭/섹션 | 내용 |
|---------|------|
| 메모 | 자유 작성 |
| 원본 | PDF, PPT, 이미지, HWP (주로 PDF) — Storage |
| AI 요약 | 같은 페이지에 **글** + **인쇄용 요약 PDF** 별도 파일 |

원본과 요약 PDF는 **별도 파일**로 저장·다운로드.
